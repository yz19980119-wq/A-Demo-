# A-Share-Quant-Trading-Framework
A股量化交易框架 | 模块化 | 严谨回测 | 实盘级工程

## 项目介绍
本项目是一套面向A股的量化交易框架，包含：
- 数据自动获取与清洗
- 标准化指标计算
- 严谨事件驱动回测
- 完整风控模块（止损/追踪止损/持仓周期）
- 交易日志与绩效分析
- 实盘信号生成

## 核心功能
✅ 模块化架构（数据/策略/回测/执行分离）
✅ 无未来函数回测
✅ 滑点、手续费、手数约束
✅ 动态仓位管理
✅ 多指标市场状态判断
✅ 自动生成明日交易建议
✅ 支持股票 & ETF

## 技术栈
Python / Pandas / Numpy / Matplotlib / Tushare
